Hovy

Gestión de mantenimiento de espacios verdes — Valle La Armonía

Asistente de turnos por WhatsApp

Hovy es el sistema con el que Valle La Armonía coordina los turnos de mantenimiento de espacios verdes con sus clientes. Su asistente de WhatsApp permite a cada cliente confirmar o reprogramar el turno propuesto para su inmueble, consultar cuándo es el próximo mantenimiento y calificar el servicio recibido.

Cómo funciona

  • El asistente responde únicamente a números registrados como clientes.
  • Cada cliente accede solo a la información de sus propios inmuebles y turnos.
  • Las respuestas son mensajes predefinidos: el asistente no genera texto libre.
  • Si un mensaje no corresponde a ninguna operación conocida, lo atiende una persona.
